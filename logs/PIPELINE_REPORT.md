## 4. 阅读这些数字时必须注意

1. **部分标注**：人工标注中位覆盖 8.5%，最低 0.8%。
   未标注的线粒体被算作假阳性，所以 Dice 是**下界**。
2. **尺度混训**：三种像素尺寸（1.004 / 2.667 / 5.291 nm/px）
   统一重采样到 4 nm/px（训练）或 8 nm/px（MitoNet 推理）。
3. **只有线粒体一类**：`organelle_type` 全部是 M，
   所以网络是同类相邻网络，不是异种细胞器互作。
4. **ER 不可用**：在检测与分割、同器官与跨器官下均低于平凡基线，
   已在 `docs/OURDATA-RESULTS.md` 记录。

## 5. 复现

```bash
python tools/run_pipeline.py --status      # 看每步状态

python tools/run_pipeline.py --from predict --force   # 换模型后重跑
```

各环节仍可单独调用，参数见对应脚本的 `--help`。
