# `tools/network/` —— 细胞器互作网络的**重建**与涌现特征度量

> 这个包补上了项目里此前**完全缺失**的一环：真正把分割出来的细胞器区域
> **连成一张网络**，然后在**这张网络**上计算指标。
>
> 原有 `code/analyze_emergent_entropy.m` 只对"每图每区域一行"的特征表逐列做
> 直方图统计，把直方图熵叫作"网络香农熵"、把幂律拟合指数经**硬编码查表**
> 叫作"李亚普诺夫指数"。那里从来没有网络，那两个名字都是错的标签。
> 本包给出的是有明确定义、有单位、并且在数据撑不起结论时**拒绝给数字**的实现。

## 1. 交互判据：我们到底在连什么

### 1.1 生物学上"互作"是什么

活细胞里可观测的细胞器互作至少有两类：

| 类型 | 物理含义 | 可观测方式 |
| --- | --- | --- |
| **膜接触位点（MCS）** | 两个细胞器的膜被栓系蛋白（tether）拉近到 **10–30 nm** | 电镜 / 超高分辨成像 + 膜间距测量 |
| **共定位 / 共运动** | 两个信号在**时间**上同步变化或同步位移 | **时间序列**成像（活细胞延时） |

### 1.2 本数据能支持什么

`data/annotations_v2` 是**单时间点**的静态图像分割结果：
每张图给出若干区域的轮廓、形态与灰度特征，**没有时间轴**。
因此上表第二类（共定位/共运动）**在原理上无法测量**——不是"没做好"，
是数据里根本没有那个维度。任何声称从本数据得到"动力学""共运动"
"信息传递"的结论都是无效的。

对第一类（MCS），我们能拿到的最近似量是**轮廓之间的像素间隙**。
`boundary_contact` 判据实现的就是它。

### 1.3 五种判据一览

| 方法 | 判据 | 参数 | 性质 |
| --- | --- | --- | --- |
| **`boundary_contact`**（默认） | 两区域**轮廓（边界像素）**的最小欧氏距离 ≤ 阈值 | 接触阈值（px） | **唯一几何上直接对应"接触"的判据** |
| `delaunay` | 质心 Delaunay 三角剖分 | 无 | 空间点模式的标准最近邻图 |
| `knn` | 每个质心的 k 个最近邻，对称化 | k、可选距离截断 | 稠密度由 k 控制 |
| `radius` | 质心距离 ≤ r | r（默认 median_nn × 1.5） | 阈值必须论证 |
| `gabriel` | Delaunay 子集：以 ij 为直径的圆内无其它点 | 无 | 比 Delaunay 稀疏，无参数 |

**为什么默认是 `boundary_contact`**：质心之间的距离与"是否接触"没有单调关系。
两个巨大的、紧贴的细胞器质心可能相距很远；两个远处的碎片质心可能很近。
只有**边界到边界**的距离才在几何上对应接触。其余四种是**质心点模式**图，
只应用于敏感性分析，不应单独作为生物学结论。

### 1.4 `boundary_contact` 的算法与权重

1. 由区域轮廓多边形光栅化出标签图（`cv2.fillPoly`，无 cv2 时退化为
   画边 + `binary_fill_holes`）。光栅化后**校验面积**与 JSON 记录值的一致性，
   偏差 > 10% 会告警。
2. 取边界像素：3×3 邻域内标签不全同的像素（两次形态学极值滤波，O(HW)，
   与区域数无关）。
3. 两个区域的最近点必然都在边界上，因此在边界像素上建 `cKDTree` 查询，
   得到**精确的**最小像素距离（不是近似）。
4. 距离 ≤ 阈值 → 一条边。
5. **权重 = 接触长度**：区域 i 的边界像素中，到 j 的边界像素距离 ≤ 阈值的
   像素个数，再与 j 对 i 的同一量取 `max` 对称化。有标定时换算成 µm。
   这是"接触面积/长度"的一维代理，**不是**真实膜接触面积。

> ⚠️ **参数命名陷阱**：CLI 参数叫 `--min-contact-px`，但它是一个**上界**——
> "距离 ≤ 该值即判为接触"。名字沿用项目既有约定，文档与报告里都显式说明。

### 1.5 `radius` 阈值是怎么来的（必须论证）

若调用方不给阈值，则用 `median_nn × radius_factor`（默认 1.5）导出，
其中 `median_nn` 是**本图内**所有区域"到最近邻质心的距离"的中位数。
取 1.5 倍的理由：在完全空间随机（Poisson）点过程下最近邻距离中位数
约为 `0.5/sqrt(λ)`，1.5 倍中位数让每个点在随机分布下平均连到约 2–3 个邻居，
既不退化成空图也不退化成全连接。

**无论阈值如何得到**，`build_network` 都会把实际使用的阈值写进
`params['radius_used']`，并回填 `params['density']`。密度接近 0 或接近 1
都说明阈值失效，会同时给出显式告警。

## 2. 为什么"空间邻近"只是互作的**代理**，不是互作本身

一条边只说明：**在这张静态图像的分割结果里，这两个区域的轮廓靠得近。**
它同时受以下每一环影响，而每一环都可能单独造假：

1. **真实间隙**——想要的那个信号；
2. **手绘轮廓误差**——标注是人类在图上描的，笔迹宽度就有几像素；
3. **轮廓简化误差**——`cv2.approxPolyDP(ε=1.5)` 把数千点压到几十点，
   在凹陷处会系统性外扩或内缩；
4. **分割遗漏/误合**——`fill_holes` 会把轮廓缺口补上，也可能把两个
   真正分开的物体并成一个；
5. **成像分辨率**——见下。

### 2.1 分辨率这道硬墙

MCS 的物理尺度是 **10–30 nm**。要让"像素间隙"有资格谈 MCS，
像素尺寸必须显著小于 10 nm。

`data/annotations_v2` 的实际标定（由 `--out` 目录下的
`REPORT.md` / `summary.json` 给出实测分布）：**本数据集并非单一标定**，
`um_per_px` 在 1.0 nm/px、2.7 nm/px、5.3 nm/px 三档之间分布，
还有 1 张图标定不可信。

即使取最细的 1.0 nm/px：

* 像素尺寸 ≈ **1.0 nm**，勉强进入"能看见 10 nm 量级间距"的门槛，
  但 10 nm 只有 10 个像素，而手绘轮廓误差本身就有 1–3 px，
  信噪比依然很差；
* **同一像素间隙在不同图里对应不同的物理长度**（差 5 倍），
  所以跨图的**绝对 µm 距离不可比较**；
* Delaunay / kNN / Gabriel 对全局尺度不变，它们的**拓扑**指标不受此影响；
  `radius` 阈值与一切以 µm 报告的绝对距离会受影响。

**结论**：本数据集的距离尺度**处于"也许能谈接触，但不足以判定 MCS"的边缘**。
报告里所有接触类的数字都必须带上标定读。

### 2.2 要做成**真正的**互作网络，还缺什么

| 缺口 | 需要的数据 | 能得到的量 |
| --- | --- | --- |
| 时间维度 | **活细胞延时成像**（同一视野 ≥ 数十帧） | 共运动/共定位 → 真正的时序互作边；转移熵才有"时间"含义 |
| 分子身份 | 每个区域的多通道标记（如 Mitotracker / ER-Tracker / LysoTracker） | `node_types` 变成真实细胞器类别 → 按类型的互作矩阵（本数据集**只有 1 类**，见 §4） |
| 膜间距 | 电镜 / STED / 超高分辨，像素 ≤ 5 nm，且标定统一 | 直接测 MCS 间距，而不是用轮廓间隙代理 |
| 栓系证据 | 已知 tether 蛋白的荧光共定位 | 把"靠近"升级为"有分子机制支撑的接触" |
| 分割质量 | 人工复核 + 不确定性估计 | 边的置信度，而不是二值的 0/1 |

在拿到上述数据之前，本包产出的网络**只能**被称为
**空间邻近图（spatial proximity graph）**。

## 3. 每个指标的精确含义、单位与限制

所有熵一律以 **bit** 为单位。所有随机过程固定种子，可复现。

| 指标 | 度量的是哪个分布 / 量 | 单位 | 限制（必须一起读） |
| --- | --- | --- | --- |
| `H_deg_bits` | 随机抽一个节点，其**度**的经验 pmf 的香农熵 | bit | 上界 `log2(N)`，**随 N 增长**，原代码正是错在拿它跨 N 比较 |
| `H_deg_max_bits` | `log2(N)` | bit | 该 N 下的熵上界 |
| `H_deg_normalized` | `H_deg / log2(N)` | 无量纲 [0,1] | **跨样本比较只能用这个** |
| `H_weight_bits` | 随机抽一条边，其**权重所属分位箱**的熵 | bit | 等频分箱下上界≈`log2(箱数)`；主要反映权重是否成簇。**必须同时报 `n_edges`** |
| `clustering_global` | 传递性 = 3×三角形 / 连通三元组 | 无量纲 [0,1] | 对**三元组**等权，不是对节点 |
| `clustering_mean_local` | 各节点局部聚类系数的算术平均 | 无量纲 [0,1] | 含度为 0/1 的节点（与 networkx 约定一致） |
| `path_length_lcc` | **LCC 上**所有节点对最短路的算术平均 | **边数（跳）** | 非连通图上无定义，因此**只在最大连通分量**上算；不是物理长度 |
| `diameter_lcc` | LCC 的直径 | 边数（跳） | 同上 |
| `degree_assortativity` | 每条边两端**度**的 Pearson 相关 | 无量纲 [−1,1] | **正则图上无定义**，此时返回 `null` 而不是 0 |
| `modularity` | 社区内边占比 − 保持度序列的零模型下的期望 | 无量纲 | `greedy_modularity_communities`；N<10 时方差极大，报告里带 `low_n_warning` |
| `mean_betweenness` | 各节点介数中心性的均值（无权最短路） | 无量纲 [0,1] | 代价 **O(N·M)**；N > 300 时**直接跳过**并说明，不估假数 |
| `H_rate_stationary` | **状态转移熵**：随机游走在图上游走时，节点离散状态序列的**马尔可夫链熵率** | **bit / 步** | **空间**转移，**不是时间**；上界 `log2(k)` |
| `H_rate_empirical` | 同上，但用状态经验占据率而非平稳分布加权 | bit / 步 | 小样本更稳，但严格说不是平稳链的熵率 |
| `MI_bits` | **相邻节点对**状态之间的互信息 | bit | **空间依赖度量，不是时间/因果度量**；样本量小则严重上偏，故同时报 `n_pairs` |
| `H_seq_rate_bits` | 按**行序**（`region_id`）的一阶马尔可夫条件熵 | bit / 步 | **伪序列，无任何动力学含义**，仅为将来接入时序留的接口 |
| `percolation_node_random` | 随机移除节点直到 LCC/N < 0.5 时的**移除比例** | 无量纲 (0,1] | 未跌破时 `fraction=1` 且 `reached=false`（表示"移除完也没跌破"，不是"阈值=1"） |
| `percolation_node_targeted` | 按**初始度**降序移除（**静态**靶向，不重算度） | 无量纲 (0,1] | 静态靶向偏向高估攻击效果，已在文档与输出中标注 |
| `percolation_edge_random` | 随机移除**边** | 无量纲 (0,1] | LCC 定义在节点上，故仍按节点 LCC 计算 |

### 3.1 状态转移熵到底在算什么

这是本项目里唯一真正配得上"涌现"二字的量：它衡量**局部状态之间的依赖结构**，
而不是某个单点特征的分布。

1. 取一个区域特征（默认 `gray_mean`），按**等频（分位）分箱**离散成
   `k` 个状态码（默认 3 箱，规则与切点写进输出）；
2. 把每个节点上的状态当作马尔可夫链的状态，**在图上做随机游走**：
   `P[i,j] = (Σ_{u:s(u)=i} Σ_{v~u} 1[s(v)=j]) / (Σ_{u:s(u)=i} k_u)`；
3. 熵率 `H = -Σ_i π_i Σ_j P[i,j] log2 P[i,j]`，其中 π 是该链的平稳分布
   （`Pᵀ` 的主特征向量）。

**这不是时间转移。** 它是"已知一个区域的状态，看它邻居的状态"的空间条件熵。
把它读成"状态随时间的演化"或"信息传递"是错的。

### 3.2 关于"李亚普诺夫指数"

**本包不在网络指标里提供任何叫"李亚普诺夫指数"的东西。**
`run_analysis.py` 默认 `--lyapunov-source none`，报告里也不会出现 λ。

`dynamics.py` 提供的是**正确的 Rosenstein (1993) 实现**，五步俱全：

1. `average_mutual_information` —— 自互信息**第一个局部极小**估延迟 τ；
2. `false_nearest_neighbors` —— 伪最近邻比例降到 **1%** 以下估嵌入维 m；
3. `time_delay_embedding` —— 相空间重构；
4. `rosenstein_divergence` —— **Theiler 窗**约束下找最近邻，算平均对数发散曲线；
5. `lyapunov_rosenstein` —— 在标度区做最小二乘，返回斜率、**R²** 与
   **`reliable`** 标志。

**可靠性是第一等公民**：样本 < 30、标度区点数 < 8、发散曲线点数 < 30、
R² < 0.90、斜率非有限——任一不满足就 `slope = None` + `reliable = False`
+ 写明原因。**绝不返回一个编出来的数字。**

标度区不靠猜：`auto_scaling_region` 用"曲线贴到饱和平台（95 分位）的
90% 处"作为终点，避开饱和段（对整条曲线做最小二乘是常见误用，
会把斜率系统性拉小）。

由于 Rosenstein 估计对 (τ, m) 高度敏感，`lyapunov_sensitivity_scan`
会对固定网格扫描并给出稳健性判据（`n_reliable` / `median_slope` /
`iqr_slope` / `consistent` / `robust`），`analyze_series` 输出
`reliability_basis ∈ {primary, sensitivity_scan, none}` 说明结论来自哪条路。

**旧接口已被显式封杀**：`dynamics.__getattr__` 会对
`infer_lyapunov_from_powerlaw` 等名字直接抛 `AttributeError` 并指向替代实现，
防止那张伪造数值的硬编码查表被无声地复制回来。

在标准测试序列上的实测表现（用于确认实现正确，不是生物学结果）：

| 序列 | 真值 λ (nat/step) | 本实现 | 是否给出数字 |
| --- | --- | --- | --- |
| logistic 映射 r=3.99，3800 点 | 0.692 | 0.531（扫描中位数，IQR 0.20） | 是（`basis=sensitivity_scan`） |
| Hénon 映射，5500 点 | 0.419 | 扫描不稳健 → 拒绝 | 否 |
| 正弦（周期轨） | ≤ 0 | 拒绝 | 否 |
| 白噪声 | 无定义 | 拒绝 | 否 |
| 6 个点的序列（**本数据集的实际规模**） | 无定义 | "样本数 6 < min_points=30" → 拒绝 | 否 |

## 4. 本数据集的已知退化（如实记录，不当发现）

* **只有 1 个细胞器类别**：带标注的区域 `organelle_type` 全部是 `"M"`；
  `recognized_text` 有 `hl` / `M` / `Ml` 三个取值，但那是 **OCR 噪声**，
  不是不同的细胞器身份。因此**任何按类型分组的指标都是退化的**，
  本流程不输出它们，报告里也会显式声明。
* **标定不唯一**：`um_per_px` 有三个不同取值（1.0 / 2.7 / 5.3 nm/px）
  + 1 张无标定 → 跨图绝对距离不可比。
* **接触阈值 2 px 下几乎无接触**：见 `REPORT.md` 的阈值敏感性表；
  这本身就是关于数据的结论（这些标注区域在图上彼此分离得很开），
  而不是 bug。
* **N 极小**：每图 0–23 个区域，中位数个位数。模块度、路径长度、
  渗流阈值在 N<10 时抽样方差极大。

## 5. 模块与依赖

```
tools/network/
├── __init__.py        包说明
├── build.py           RegionTable / OrganelleNetwork / 5 种邻接判据 / 序列化
├── metrics.py         度分布熵、边权熵、聚类、路径、同配、模块度、状态转移熵、MI、鲁棒性

└── README.md          本文件
```

依赖：`numpy`、`scipy`（必需）；`networkx`（模块度、介数，缺失时相关指标
返回 `null` 并说明）；`cv2`（光栅化，缺失时有 numpy 退化路径）。
`pandas` / `scikit-learn` **不需要**。

`OrganelleNetwork` 支持 JSON+npz 往返：

```python
from tools.network import build
net = build.OrganelleNetwork.load("data/network_analysis_all/networks/11_0002.json")
print(net.n_nodes, net.n_edges, net.density(), net.coordinate_unit)
```

## 6. 引用本包结论时的最小清单

报告任何来自本包的数字时，必须同时给出：

1. **邻接判据**与**全部参数**（尤其接触阈值、k、半径）；
2. **图密度**（判断阈值是否失效）；
3. **N**（节点数与参与汇总的图数）；
4. 熵类指标要说明是**原始**还是**归一化**版本；
5. 状态类指标要说明是**空间**量；
6. 跨图比较绝对距离时要说明标定是否唯一。

`REPORT.md` 会自动带上以上全部内容，以及一节
**"局限 / 这些数字说明了什么、不能说明什么"**。
