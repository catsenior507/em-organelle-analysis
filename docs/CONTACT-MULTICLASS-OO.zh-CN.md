# 五类细胞器的接触分析：全局与局部，均无富集

[English](CONTACT-MULTICLASS-OO.md) ｜ **中文**

> 数据：OpenOrganelle 四个 crop（HeLa / Jurkat / 巨噬细胞 ×2），4.0 nm 各向同性。
> 标注为**语义分割**（每类一个二值掩码），不是实例分割。
>
> **结论**：无论用全视野零模型还是局部块内零模型，**没有任何类别对的接触量
> 超过"保持各自形态、随机摆位"的期望**（全局 0/55 显著，局部 0/976 显著）。
>
> 但这个"负富集"衡量的是**空间组织**（细胞器分区占据），不是"膜能否接触"。
> 距离剖面显示接触在 8 nm 以下极少、自 16 nm 起迅速增加，
> **正好落在膜接触位点 10–30 nm 的经典窗口内**。两者不矛盾，见 §4。

---

## 1. 为什么要做两种零模型

**全视野零模型**：把一类整体环面平移，看接触量是否超过随机摆位。
它回答的是"这两类在整个视野里是否倾向于待在一起"。

**局部块内零模型**：把体积切成 96³ 体素（384 nm）的块，只在两类都显著存在的块里
做同样的平移检验。它回答的是"在两类共处的局部环境里，它们是否比随机更贴近"。

两者测的不是同一件事。全视野版本会被**细胞器分区占据**主导：这些 crop 横跨多个
细胞，高尔基体偏一侧、溶酶体偏另一侧，任何随机平移都会把一类挪到另一类不存在的
区域，于是 z 必然极负。局部版本把大尺度分隔吸收进块边界。

零模型：环面平移 + FFT 互相关，**一次覆盖全部 n³ 个平移**（`n_shifts` 记录为
1.7×10⁸ 量级），p 值无抽样误差。

| 项 | 值 |
|---|---|
| 测量组数 | 55 |
| 显著高于零模型（p<0.05） | **0 / 55** |

| 富集比中位数 | **0.000**（最大 0.006） |

| endo–er | 48 | 66 | 1077 | 4770 | 7196 | **10694** | 4 |
| er–mito | 0 | 0 | 438 | 3162 | 6858 | **10573** | 3 |
| golgi–ves | 0 | 8 | 593 | 2201 | 5896 | **10474** | 4 |
| er–lyso | 0 | 0 | 28 | 1771 | 5325 | **8452** | 4 |
| er–golgi | 78 | 94 | 223 | 1128 | 3911 | **7278** | 4 |
| endo–golgi | 0 | 6 | 340 | 1164 | 2522 | **4087** | 4 |

## 4. 怎么读"16 nm 以下几乎恒为 0"

这里有一个容易走错的地方，我先走错了一次，记下来。

**第一反应**：语义掩码勾的是细胞器内部，膜间隙未被标注，所以"掩码相邻"在结构上
就不等于"膜接触"，16 nm 是标注精度的下限、不是生物学阈值。

**于是去查了膜通道**：OpenOrganelle 每个 crop 都有 `*_mem`。若膜掩码能给出真实膜间距，
接触剖面应当明显前移。实测结果：

| | golgi:er（整类） | golgi_mem:er_mem（膜） |
|---|---|---|
| 0 nm | 0 | 0 |
| 8 nm | 0 | 0 |
| 16 nm | 96 | 96 |
| 24 nm | 1335 | 1335 |

**两条剖面几乎完全相同。** 一开始以为是读错了文件，核查后确认不是：

```
golgi     前景 10,487,793 (6.12%)
golgi_mem 前景  4,711,271 (2.75%)
golgi ∩ golgi_mem = 4,711,271   ← 恰等于 golgi_mem 全体
```

即 **`*_mem` 是整类掩码的子集，勾的就是外表面**。

**所以两条剖面必然相同**：对体素之外的点来说，到整类掩码的距离与到其外表面的距离
是同一个数。用膜通道不会改变距离剖面。

**正确的解读因此是**：
掩码边界**就是**膜的边界，掩码间距**就是**膜间距。0 nm 处无接触不是标注缺陷，
而是因为**互相接触的膜会融合，本来就不存在"零距离的两层膜"**。
接触自 16 nm 起迅速增加、至 24–40 nm 达高峰，这**正好落在膜接触位点
10–30 nm 的经典窗口内**。

也就是说，§3 的距离剖面不是伪影，而是本数据能支持的、与 MCS 定义一致的测量。
我最初"16 nm 是标注精度下限"的判断过强，这里更正。

> 仍然成立的一点：**富集比 <1 与"没有接触"是两件事。**
> 富集比比较的是"实测接触 vs 随机摆位"，它衡量的是空间组织（分区占据），
> 而距离剖面衡量的是"最近能近到多少"。前者为负、后者在 16–40 nm 有大量接触，
> 两者并不矛盾。

## 5. 局部结果

块大小 96³ 体素（384 nm），步长 48；只保留两类各 ≥2000 体素的块；
块内做 200 次随机环面平移。

| 类别对 | 块数 | obs>0 的块 | 汇总富集 | 显著富集块 |
|---|---|---|---|---|
| endo:er | 320 | 91 | **0.01** | 0 / 320 |
| golgi:ves | 242 | 97 | **0.01** | 0 / 242 |
| er:mito | 170 | 33 | **0.00** | 0 / 170 |
| golgi:er | 244 | 42 | **0.00** | 0 / 244 |

汇总富集 = `Σ实测 / Σ零模型期望`。**全部远低于 1，且无一块显著。**

放宽块选择（两类各 ≥100 体素）、换块大小（64³）与容差（16/24 nm）后结论不变：

| 设置 | obs>0 块数 / 总块数 |
|---|---|
| 64³，16 nm | 69 / 789 |
| 64³，24 nm | 191 / 789 |
| 96³，16 nm | 115 / 775 |
| 96³，24 nm | 242 / 775 |

即：**在 70%–90% 的"两类共处"的局部窗口里，两者在 24 nm 内根本不接触。**

扩展到 15 个类别对、三种细胞类型，并补充了局部尺度的验证。

## 7. 一个被否证的做法（保留作记录）

我先写了一个用**体积内均匀随机分布**作零模型的版本（`contact_matrix.py`），
得到所有类别对的富集比在 0.00–0.05。那个数字不可解释：

组织里细胞器分区占据，均匀随机重排会把它们混在一起，于是任何类别对都显示
"远低于随机"。**问题在零模型，不在生物学。** 换成保持形态的环面平移后，
量级从 0.00 变成 0.00——但因为尺度不同，结论的可解释性完全不同。

该脚本已标注为**已废弃**，其结果不再用于任何结论。

## 8. 局限

1. **语义标注，非实例**：只能回答"两类膜是否靠得近"，不能回答
   "每个高尔基体接触几个内质网"。
2. **标注口径决定了 16 nm 的下限**：更精细的接触分析需要膜级别的标注
   （OpenOrganelle 有 `*_mem` 通道，本项目未使用，见 §9）。
3. **四个 crop 来自三种细胞**，跨 crop 汇总只作参考。
4. **线粒体只在 3 个 crop 有数据**（crop4 的 mito 为空），含 mito 的 5 组被跳过。
5. 局部零模型假设块边界周期相连，边缘的少数体素会被重复计入；
   块大小与最小体素阈值都会影响结果，因此做了参数扫描（见 §5）。

## 9. 若要继续

1. **检验膜接触位点的极性**：MCS 不是随机分布在细胞器表面，而是富集在特定区域
   （如线粒体与 ER 的接触集中在 ER 的管状网络处）。本文只统计了总量，
   没有做"接触在表面上的分布是否均匀"这一步。
2. **加入更多细胞类型**：目前是 HeLa / Jurkat / 巨噬细胞。若要谈细胞类型差异，
   四个 crop 太少。
3. ~~用膜通道重做~~：**已试，结论见 §4**——`*_mem` 是整类掩码的子集（外表面），
   距离剖面与整类完全相同，不带来新信息。
