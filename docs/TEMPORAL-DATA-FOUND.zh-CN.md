# 找到了：S-BIAD712 的活细胞多细胞器时间序列

[English](TEMPORAL-DATA-FOUND.md) ｜ **中文**

> 此前 `TEMPORAL-DATA-SEARCH.zh-CN.md` 的结论是"**不存在**带时间轴的多细胞器数据，
> 动力学无从成立"。**这个结论需要修正。**
>
> 不存在的是**电镜**时间序列（固定制样，结论不变）；但**荧光**的多细胞器时间序列
> 是存在的，而且已公开、已可读、已跑通初步分析。

---

## 1. 找到的数据

**S-BIAD712**（BioImage Archive，Cohen lab, UNC），CC BY 4.0。

| 项 | 值 |
|---|---|
| 内容 | **活**人 iPSC（KOLF2.1J），7 种细胞器同时标记 |
| 标记 | 核、溶酶体、线粒体、高尔基体、过氧化物酶体、内质网、脂滴 |
| 时间点 | **25–100 帧**（中位 100） |
| 文件 | 32 个时序 + 35 个单张 Zstack，共 67 个 / 32.5 GB |
| 重复 | 3 个生物学重复（13 / 8 / 11 个视野） |
| 尺寸 | 768 × 768，8 通道（7 细胞器 + 1 残差），uint16 |
| 像素 | **79.87 nm** |
| 设备 | Zeiss 880 共聚焦，63×/1.4 NA，1.90 s/帧 |

### 1.1 为什么可以确定它是真时序

描述不可信——同一批数据的**另一个**研究（S-BIAD2983）描述里也写
"timelapse images were acquired"，但 4518 个文件里含时间编号的是 **0 个**，
存的全是快照。所以对 S-BIAD712 做了四项独立验证：

| 验证 | 结果 |
|---|---|
| CZI 头部维度 | `SizeT = 25`，`SizeZ = 1`，`SizeC = 8` |
| XML 标志 | `TimeSeries = true` |
| 前两帧是否相同 | **否**，首末帧平均绝对差 3808（通道 0） |
| 同一视野的时序还是不同视野的 tile | **同一视野**：细胞核相邻帧 IoU **0.891**，首末帧 0.874 |

最后一项是关键。若这些帧是不同视野（协议里确实提到 "Tile series"），
细胞核的帧间 IoU 会接近 0。实测 0.891 说明是同一个细胞在时间上推进。

## 3. 时间标定：一个无法解决的歧义

这是必须写清楚的一点。

XML 里 `FrameTime = 1.896 s`（扫描一帧的耗时），而
`Interval = 1 ms`。**1 ms 的间隔在物理上不可能**——单帧就要 1.9 秒。

两种解释：

- 采集是**连续**跑的（无延迟），真实间隔 ≈ 1.9 s → 25 帧约 **47 秒**；
- 或者间隔字段被错设，真实间隔远大于此 → 总时长可能是数十分钟。

CZI 里本来应有逐帧时间戳，但这个文件的元数据段里 `TimeStamp` 标签数为 **0**，
无法从文件本身判定。

**因此本文所有动力学量以"帧"为单位报告，不换算绝对速度。**
凡涉及 nm/s 的数字都标注为"假定间隔 = 1.90 s"，且不可与其他文献的绝对速度直接比较。

## 4. 初步动力学分析

对一个文件（`TS_PBTOhNGN2hiPSCs_BR1_N08`，25 帧）跑了完整流程：
逐帧 Otsu 分割 → 类别对接触序列 → 循环时间平移零模型。

### 4.1 细胞器确实在动

| 细胞器 | 相邻帧 IoU | 首末帧 IoU |
|---|---|---|
| 核 | 0.891 | 0.874 |
| 线粒体 | 0.668 | 0.425 |
| 内质网 | 0.687 | 0.549 |

线粒体与内质网的首末 IoU 降到 0.43/0.55，说明 25 帧内发生了实质重排；细胞核几乎不动
（0.874），符合预期，也反证了视野稳定。

### 4.2 多数类别对的"接触"是静态交织，不是动力学

接触判据 1 像素（≈ 80 nm），循环平移零模型：

| 类别对 | 接触帧 | 概率 | 生成 | 消解 | 时间 CV | 富集 |
|---|---|---|---|---|---|---|
| mitochondria:er | 25/25 | 1.00 | 1 | 1 | 0.14 | 1.01 |
| er:golgi | 25/25 | 1.00 | 1 | 1 | 0.11 | 1.01 |
| er:lysosome | 25/25 | 1.00 | 1 | 1 | 0.08 | 1.02 |
| er:lipid_droplet | 25/25 | 1.00 | 1 | 1 | 0.08 | 1.04 |
| mitochondria:golgi | 25/25 | 1.00 | 1 | 1 | 0.37 | 0.95 |
| golgi:lysosome | 23/25 | 0.92 | 3 | 3 | 0.82 | 0.95 |
| **mitochondria:lysosome** | **9/25** | **0.36** | **5** | **5** | **1.74** | **0.42** |

**富集 ≈ 1.0 的含义**：把 B 的时间序列整体循环平移后，接触量几乎不变。
也就是说这些接触**完全由静态空间交织解释**，没有额外的时间协同——
内质网与线粒体在整个细胞里本来就互相穿插，光靠"相邻"判据必然得到持续接触。

**唯一真正有动态的是线粒体–溶酶体**：接触概率 0.36（不是常开），
时间 CV 1.74（波动大），5 次生成 + 5 次消解（真实的事件），
而富集 0.42 表示它比时间平移零模型**更少**接触——溶酶体在有接触与无接触之间切换，
而不是持续贴靠。

### 4.3 一个不能忽视的混淆

细胞核在 25 帧内净位移 7.2 像素（约 575 nm），线粒体 32 像素，高尔基体 41 像素。
逐帧位移方向的一致性只有 0.40（1.0 = 完全同向），且高尔基体与线粒体**反向**移动，
所以这不是载物台漂移。

但高尔基体的绝对速度（按 1.9 s 间隔）会达到 ~1.1 μm/s，偏快。
这再次说明**绝对速度不可靠**，只有相对比较（哪个动得多、哪个有接触事件）可用。

## 5. 这对整篇论文意味着什么

原来的表述"动力学指标在静态快照上原理上不适用"**仍然成立**——它说的是
李雅普诺夫指数那类相空间量，那确实需要时间序列，且电镜快照没有。

但"**没有任何带时间轴的数据**"这句话要改成：

> 公开的**电镜**时间序列不存在（固定制样所限）；但公开的**荧光**多细胞器时间序列存在
> （S-BIAD712，7 种细胞器，25–100 帧）。因此动力学在**光学分辨率**下是可算的，
> 只是它的量级（μm、秒）与膜接触位点的量级（nm、毫秒到秒）不重叠。

两者是互补而非替代：电镜给结构，荧光给动力学。

## 6. 复现

```bash
# 取最小的一个时序文件（236 MB）
curl -sSL -o data/biad712/TS_BR1_N08.czi \
  https://ftp.ebi.ac.uk/biostudies/fire/S-BIAD/712/S-BIAD712/Files/TS_PBTOhNGN2hiPSCs_BR1_N08_Unmixed.czi

# 验证维度、通道、时间维真实性
python tools/validate_biad712.py

# 接触动力学（接触判据 1 px ≈ 80 nm）
python tools/dynamics_biad712.py --dilate 1
```

辅助脚本：`tools/probe_czi.py`（只取文件头，不整包下载）、
`tools/walk_biad.py`（遍历任一 S-BIAD 研究判断是否含时序）。

## 7. 局限

1. **只跑了一个文件、一个视野**。32 个时序文件里还有 31 个未分析，结论是初步的。
2. **时间标定未定**，绝对速度不可报。
3. **阈值分割代替人工标注**，绝对数值不可与电镜结果比较。
4. **光学分辨率 80 nm/像素**，无法分辨 10–30 nm 的膜间距，因此这里的"接触"
   与电镜里的"膜接触位点"不是同一个量。
