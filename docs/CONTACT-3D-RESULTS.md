## 2. 指标定义（写论文时照此表述）

- **严格接触**（`tol = 0 nm`）：线粒体表面体素与内质网体素**共享面元**（6-邻接）的数量。
  这是"两者膜在分割结果上直接相连"的判据。
- **容差接触**（`tol = 16/32/64 nm`）：线粒体表面体素在给定物理距离内"够得着"内质网
  的面元数。用**纳米**而非体素指定，因为 8 nm 与 4 nm 的数据必须能放在同一尺度上比。
- **`frac`**：上述面元占线粒体总表面体素的比例（无量纲，可跨体积比较）。
- **零模型**：把内质网整体在体积内做**环面平移**，用 FFT 互相关**一次算出全部 n³ 个
  平移**下的接触值，得到**精确**零分布（300³ → 2700 万个平移；200³ → 800 万个）。
  `p = #{平移 : 接触 ≥ 观测} / n³`，**没有抽样误差**。

## 3. 结果

### 3.1 严格接触几乎不存在，贴合出现在 32–64 nm 尺度

| crop | 体素 | 线粒体表面体素 | 严格接触 0 nm | 16 nm | 32 nm | 64 nm |
|---|---|---|---|---|---|---|
| 129 | 8 nm | 339,296 | **9,369** (2.76%) | 17,255 (5.09%) | 29,504 (8.70%) | 54,281 (16.0%) |
| 140 | 4 nm | 179,052 | **0** | 63 (0.04%) | 13,001 (7.26%) | 27,835 (15.5%) |
| 141 | 4 nm | 64,843 | **0** | 0 | 891 (1.37%) | 9,314 (14.4%) |
| 147 | 4 nm | 211,756 | **0** | 5,146 (2.43%) | 10,279 (4.85%) | 19,378 (9.15%) |
| 148 | 4 nm | 86,200 | **0** | 3,406 (3.95%) | 10,793 (12.5%) | 26,968 (31.3%) |

**读法**：5 个 crop 里有 4 个在**零距离上完全没有** mito–ER 接触；但把容差放宽到
32–64 nm，9%–31% 的线粒体表面就"够得着"内质网了。

这与已知的**线粒体相关膜（MAMs）**几何一致：内质网与线粒体外膜之间存在
**10–30 nm 的间隙**，而不是融合。分割掩码在 4/8 nm 体素下无法把这个间隙分辨成
"零距离接触"，所以严格接触判据会给出 0；必须用纳米级容差才看得到贴合。

### 3.2 线粒体与内质网在空间上**相互回避**，不是共定位

| crop | 观测量 | 零模型均值 | z | p |
|---|---|---|---|---|
| 129 | 9,369 | 30,984 | **−3.94** | ≈1.0 |
| 140 | 0 | 9,523 | **−4.61** | 1.0 |
| 141 | 0 | 7,019 | **−1.63** | 1.0 |
| 147 | 0 | 9,350 | **−3.30** | 1.0 |
| 148 | 0 | 15,975 | **−2.94** | 1.0 |

全部 5 个 crop 的观测接触都**低于**随机平移的期望值，z 从 −1.63 到 −4.61。

**这不是"没有互作"**，而是：在这几块肾组织里，线粒体与内质网占据**不同的空间区域**
（内质网偏核周、线粒体偏基底），把内质网随机搬一个位置，反而更容易撞上线粒体表面。

`p ≈ 1.0` 是因为这是**单侧富集检验**（问"是否比随机更靠近"）；答案是否定的。
若要检验"是否显著更远"，应对应看 z 的负值。

## 4. 必须写进论文的局限（这些不是客套话，是本结果的边界）

1. **样本量极小**：5 个 crop，来自**1 个数据集、1 只小鼠的肾脏**。任何跨器官/跨物种的
   结论都不成立。
2. **环面零模型假设周期性**：体积边界被当成与对侧相连。对有靠近边界的结构，这会
   人为让两侧"接上"。已在合成数据上量化：与"先平移再膨胀"的定义相比，
   边界效应 ≤ 0.92% 面元。
3. **8 nm 与 4 nm 不可混算**：crop129 是 8 nm 体素，无法分辨 <16 nm 的间隙。
   它的"严格接触 9,369" 很可能只是 8 nm 采样把一个 <16 nm 的间隙抹成了相连。
   **跨分辨率比较只能看 nm 口径的容差列，不能看严格接触列。**
4. **分割本身可能制造间隙**：标注者倾向于不让两个细胞器的掩码相连，
   这会把真实接触系统性地变成 1–2 体素间隙。容差剖面在一定程度上缓解了这一点，
   但不能消除。
5. **这是接触几何，不是功能互作**。要谈"互作"，还需要时间上的共变或分子机制证据。
   本项目**没有**真实时间序列（见 `docs/INTEGRITY-NOTES.md`）。
6. **零模型只平移，不改变形状**。它检验的是"位置偏好"，不能排除
   "两者形状本身就是为了互相贴合而演化"这种解释。

## 5. 方法学上踩过并修掉的三个坑（都影响结论，值得记录）

### 5.1 零模型退化成"什么都没变"

第一版零模型用"仅在体积内合法位置重放"。真实数据里 `er` 有 **23–33 个连通分量
散布全卷**，包围盒几乎等于整卷 → 合法平移范围坍缩为 0 → 50 次抽样全部等于原位置
→ 零分布与观测**完全相同**（`obs == null_median == null_max`，p 恒为 1.0）。

已用 48³ 合成场景**复现**该退化并加了 `degenerate_null` 自动检测。
改用环面平移后不再退化。

### 5.2 容差用体素数表示 → 跨分辨率不可比

v2 用 `tol=8 体素`：对 8 nm 数据是 64 nm，对 4 nm 数据只有 32 nm。
三个 crop 的剖面根本不在同一物理尺度上。v3 起改为按 **nm** 指定。

### 5.3 暴力零模型跑不动 → 改 FFT 精确解

6 个体积 × 200 次重定位 × 300³ 体素，十分钟都跑不完。
利用"平移与膨胀可交换"把问题化成一次互相关：

```
contact(shift) = Σ_x S_A(x) · D(x − shift),   D = dilate(B, 1)
```

一次 FFT 就得到**全部 2700 万个平移**的接触值，既快又给出精确 p 值。
已逐项验证 FFT 与暴力实现在同一定义下**完全相等**；
两个定义（先膨胀再平移 vs 先平移再膨胀）在周期边界上的差异 ≤ 0.92%。

## 6. 复现步骤

```bash
# 服务器上
conda activate dachuang
cd ~/dachuang_organelle

# 1) 拉标签（并发，约 2 分钟/体积）
python scripts/fetch_labels.py --dataset jrc_mus-kidney --labels mito,er \
    --out data/labels \
    --eligible-cache data/eligible_crops_jrc_mus-kidney.json --max-crops 6

# 2) 接触分析（FFT 精确零模型 + nm 容差）
python scripts/contact_analysis_3d.py --labels data/labels --pairs mito:er \
    --out data/contact_3d_v4 --manifest data/train_crop_manifest.csv \
    --tol-nm 0,16,32,64 --tol 1 --null-mode fft
```

   才能谈"这块组织里的规律"。
